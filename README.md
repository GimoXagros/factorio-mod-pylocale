# pylocale

## Repository version and installation

This repository contains `pykoreanlocale` source version `1.1.0`. Its [info.json](info.json) declares Factorio `0.17`. These metadata describe this checkout and do not establish compatibility with newer Factorio versions.

For packaged installation, use the [pykoreanlocale Mod Portal downloads](https://mods.factorio.com/mod/pykoreanlocale/downloads) and select a file for your installed Factorio version. Portal releases can differ from this checkout. Put the downloaded mod ZIP in your Factorio user data `mods` directory and install the required dependencies listed in the manifest; entries prefixed with `?` are optional.

This repository has no GitHub Releases.
